# 🎮 Gestão de Tarefas Gamificada

## 📖 Descrição

Projeto de desenvolvimento de software com foco na criação de um sistema de organização de tarefas com elementos de gamificação, simulando um ambiente corporativo com incentivos por desempenho.

---

## 🎯 Objetivo

Desenvolver uma solução que incentive a realização de tarefas por meio de recompensas, utilizando mecânicas de jogo para aumentar o engajamento dos usuários.

---

## ⚙️ Funcionalidades

* Cadastro e gerenciamento de tarefas
* Sistema de progressão baseado em conclusão de atividades
* Avanço em tabuleiro conforme tarefas realizadas
* Sistema de sorteio (dado) ao atingir determinadas posições
* Recompensas simuladas para incentivo ao usuário

---

## 🛠️ Tecnologias Utilizadas

* JavaScript
* HTML
* CSS

---

## 🧠 Minha Atuação

* Participação no desenvolvimento do projeto em equipe
* Definição da lógica de gamificação
* Estruturação das regras de progressão no sistema
* Apoio na organização e documentação do projeto

---

## 📁 Estrutura do Projeto

O sistema foi desenvolvido com base em conceitos de desenvolvimento de software, incluindo definição de regras de negócio, lógica de progressão e organização de funcionalidades.

---

## 🚀 Resultados

O projeto permitiu aplicar conceitos de lógica de programação e desenvolvimento de sistemas, além de explorar estratégias de gamificação para engajamento de usuários.
